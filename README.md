# Super Admin Dashboard Management System

A responsive Super Admin Dashboard Management System built with React, TypeScript, Vite, React Router, and TanStack Query.

## 🚀 Live Demo

https://santoshm15.github.io/super-admin-dashboard-management/

## 📂 GitHub Repository

https://github.com/Santoshm15/super-admin-dashboard-management

## ✨ Features

- Super Admin Dashboard
- User Management
- Tenant Management
- User Details
- Tenant Details
- User Search and Filtering
- User Status Management
- User Role Management
- User Pagination
- Tenant Statistics
- User Statistics
- Recent Activity
- Dashboard Statistics
- TanStack Query data fetching
- Loading and error states
- Responsive design
- GitHub Pages deployment

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- TanStack React Query
- React Router
- CSS
- DummyJSON API
